## 0:注意事项
1.关于编译和运行
编译->将你写的.c文件编译为.exe文件
运行->将你编译得到的.exe文件运行

如果你修改了代码但只点了运行**你的修改是不会被应用到程序上的**，会导致代码有时候已经能够通过，但本地测试还不通过的问题。

推荐同学们选择编译并运行的快捷键 DEVC++:F11 VSCode:F5

## 3: 奇数还是偶数
这题有一个小事故，课上并没有讲关于负数取模的一个性质，即负数取模依旧会得到负数。
如-8 mod 3 = -2
导致写if(n%2==0)...else...的同学通过，但是if(n%2==1)...else...的同学却得到了WA
因此后面删除了负数的数据点。

## 6: 空城计
这道题时间限制比较宽松，从1开始枚举合法的最小公倍数也可以通过，但还是鼓励大家学习题解的做法。
样例代码
```c
#include <stdio.h>
int main()
{
    int a, b;
    scanf("%d %d", &a, &b);
    if (a == 0 || b == 0)
    {
        printf("0\n");
        return 0;
    }
    int c = 1;
    while (c % a != 0 || c % b != 0)//枚举最小公倍数
    {
        c++;
    }
    printf("%d\n", c);
    return 0;
}
```
注意逻辑运算的符号，`||` `&&` `!`分别表示自然语言中的或、且和否定。特别的，`!=`是不等于,单独写一个`0`为假，`1`及其他任何数字为真
如
```c
//不会自然终止的循环
while (1)
{
    printf("endless...\n");
}
```
```c
//寻找第一个a的倍数
int c=a+1;
while (!(c % a != 0))//与c % a == 0等价
{
    c++;
}
```
## 7: Credits
