## 寻找最大值

| 难度 | 考点 |
| --- | --- |
| 待评 | 二分、区间性质、交互协议 |

### 题目分析

维护一个始终包含全局最大值的区间 $[l,r]$。询问这个区间，得到次大值的位置 $s$，再将区间分成左右两半。考虑包含 $s$ 的那一半：如果最大值也在这一半，那么这一半的次大值仍然是 $s$；如果最大值在另一半，那么 $s$ 自己就是这一半的最大值，该半区的次大值一定不是 $s$。因此，只需要再询问包含 $s$ 的半区，就能确定最大值应该留在哪一半。

若包含 $s$ 的半区只有一个位置，则无法合法询问，但这个位置只放着当前区间的次大值，最大值必然在另一半。代码用返回值 `0` 表示这个无需发送询问的特殊分支；真实回复的下标至少为 $1$，不会混淆。

初始区间包含整个排列，显然包含最大值。每轮按上述规则保留的半区仍包含最大值，因此这个不变量一直成立。当区间缩小为单个位置时，该位置就是答案。

每轮区间长度至多变为原长度的一半向上取整，且最多发送两次询问，因此总询问次数不超过 $2\lceil \log_2 n\rceil$。在 $n\le 10^5$ 时至多 $34$ 次，小于限制 $40$。选手程序的时间复杂度为 $O(\log n)$，额外空间复杂度为 $O(1)$，所有整数均可使用 `int`。重复询问不会影响正确性，只要计入次数即可。

本 OJ 会先进行一次预运行。程序初次读到 $n=0$ 时正常退出；正式交互重新启动程序后会读到合法的 $n$。这不改变算法。必须在输出询问后刷新缓冲区，再读取回复。读到 `-1` 或输入结束时立即退出；输出最终答案后结束程序，不等待额外确认。隐藏排列只属于交互程序，不能从选手的初始输入中读取。

### 示例代码

```c
#include <stdio.h>
#include <stdlib.h>

int ask(int l, int r) {
    if (l == r) return 0;
    printf("? %d %d\n", l, r);
    fflush(stdout);
    int s;
    if (scanf("%d", &s) != 1) exit(0);
    if (s == -1) exit(0);
    return s;
}

int main(void) {
    int n;
    if (scanf("%d", &n) != 1 || n == 0) return 0;
    int l = 1, r = n;
    while (l < r) {
        int s = ask(l, r);
        int mid = (l + r) / 2;
        if (s <= mid) {
            if (ask(l, mid) == s) {
                r = mid;
            } else {
                l = mid + 1;
            }
        } else {
            if (ask(mid + 1, r) == s) {
                l = mid + 1;
            } else {
                r = mid;
            }
        }
    }
    printf("! %d\n", l);
    fflush(stdout);
    return 0;
}
```
