## 0:注意事项
1.关于编译和运行
编译->将你写的.c文件编译为.exe文件
运行->将你编译得到的.exe文件运行
如果你修改了代码但只点了运行**你的修改是不会被应用到程序上的**，会导致代码有时候已经能够通过，但本地测试还不通过的问题。
推荐同学们选择编译并运行的快捷键 DEVC++:F11 VSCode:F5 
其他编辑器或者编辑器配置非默认设置的情况可以问ai或者网上搜。
2.关于使用ai
在经历了去年期末平均分怒掉一道题的惨案后，助教们决定今年严查ai。
请各位同学不要在C赛使用ai。同时，毕竟是上机测试，也请减少交头接耳的情况。
关于前三四道题不会做可以问助教，或者查课件。往往前几道题都是课件改编，难度不会很大。
E赛虽然不做监管，但还是希望同学们独立思考。
3.关于设备
请各位同学如果使用游戏本的话****一定****要带充电线！因为有些教室插座较少，推荐每个宿舍再带个插线板以防万一。
4.关于提交
**不推荐直接在oj的提交框内直接写答案。** 推荐先在本地编辑器上完成，编译运行且样例通过再进行提交。
个别同学不熟悉复制粘贴的快捷键 复制: Ctrl+C 粘贴:Ctrl+V
提交后只有得到AC才是通过，出现WA CE PE等情况请在考试简介处查询是哪里出现了问题

## 3: 奇数还是偶数
这题有一个小事故，课上并没有讲关于负数取模的一个性质，即负数取模依旧会得到负数。
如-8 mod 3 = -2
导致写if(n%2==0)...else...的同学通过，但是if(n%2==1)...else...的同学却得到了WA
因此后面删除了负数的数据点。
## 4: Dlyrotz
~~助教玩音游导致的~~
主要在于循环的基础运用，使用while循环的实现如下
```
#include<stdio.h>
int main() {
    int i = 1, n;
    scanf("%d", &n);
    printf("<");
    while(i<=n){
        printf("=");
        i = i + 1;
    }
    printf(">");
    return 0;
}
```
## 5：Glaciaxion
方法很多，你可以先算出来首项每次加一个公差，也可以选择每次用等差数列通项公式计算第i项
出现了大量的PE，源于`printf("%d",...);`中的%d后面没有加空格，导致输出的数字挤在了一起。
正确的版本为`printf("%d ",...);`
